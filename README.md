## 👋 Hola, soy David Machado

Desarrollador Full-Stack con pasión por crear soluciones robustas, elegantes y escalables. Trabajo principalmente con **React**, **Next.js**, **TypeScript**, **Python** y arquitecturas modernas, combinando rendimiento con una experiencia de usuario cuidada.

> *"No soy un capitán que navega solo. Con mi tripulación construyo productos de punta a punta."*

### 🚀 Mi tripulación — tecnologías y herramientas

**Cubierta (Frontend):** React · Next.js · TypeScript · Tailwind CSS · Three.js · shadcn/ui · Zustand · Framer Motion  
**Sala de máquinas (Backend):** Node.js · Express · Fastify · FastAPI · WebSockets · Zod  
**Bodega (Datos):** PostgreSQL · Supabase · Prisma · SQLite · Drizzle ORM · pgvector  
**Astillero (Herramientas):** Git · GitHub · Docker · VS Code · Arch Linux · Playwright · Vitest
